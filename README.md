# Tepore add-on repository

Home Assistant add-on repository for Tepore, a local-first heating engine. In Home Assistant: Settings → Add-ons →
Add-on store → ⋮ → Repositories, add `https://github.com/flevanti/tepore-addon`, then install **Tepore**.

This repository holds only the add-on's metadata; the add-on runs the published image
`ghcr.io/flevanti/tepore-{arch}`. It is updated automatically by each release.
